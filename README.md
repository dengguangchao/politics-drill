# 政治理论排坑练习

把《政治理论·小黑排坑手册》里的 229 条表述做成了可以反复刷的练习工具。纯网页，不用装任何东西。

## 怎么用

解压后双击 `index.html`，浏览器打开就能练（推荐 Chrome / Edge / Safari）。做题记录存在浏览器本地，换浏览器或清缓存会丢，同一个浏览器里可以一直续着练。

## 四种练法

| 练法 | 做什么 | 适合什么时候 |
| --- | --- | --- |
| 判断改错 | 读手册原句判对错，错的当场看红笔批改 | 最贴近考场，默认从这个开始 |
| 关键词四选一 | 句子挖掉主角关键词，四个近似词里选回来 | 已经读过一遍，练辨析 |
| 默写填空 | 把关键词打出来 | 考前查漏，暴露"看着眼熟其实写不出" |
| 闪卡速记 | 关键词全部盖住，先背再翻面 | 通勤、排队等碎片时间 |

判断题可以打开"变式"：正确表述也会被随机换掉一个词，防止靠"这句长得眼熟"蒙对。

## 其他几块

- **错题与收藏**：做错自动进错题本，连续答对两次自动移出；重点句子可以点☆收藏。两个列表都能直接开练。
- **通读手册**：按章节读正确表述，红字是原手册挖的坑。点"盖住关键词"可以边读边自测。
- **学习进度**：累计正确率、过关条数，以及每一章的掌握情况。配置页点"只选薄弱章节"会自动勾出正确率低于 80% 和还没练过的章节。

## 键盘操作

- `1` / `2`：判断正确 / 有坑；选择题按 `1`–`4` 选项
- `空格`：翻面、进入下一题
- 填空模式按回车对答案

## 目录结构

```
index.html          页面
assets/style.css    样式
assets/data.js      题库（229 条，可自己增删）
assets/app.js       逻辑
```

## 自己加题

打开 `assets/data.js`，按现有格式往对应章节的 `items` 里加就行：

```js
{ t: "近年来{{重点领域||次要领域}}取得了新的发展成果。" }
```

- `{{正确表述||手册原句的错误表述}}` —— 这就是一个"坑"。判断题会显示错误版本，四选一会把正确表述挖掉，错误表述自动变成干扰项。
- `{{关键词}}` —— 整句正确，但这个词是考点，会被用来出选择题和填空题。
- `n: "补充解析"` —— 可选，答完显示。
- `bad: true` —— 整句错误又没法靠换词修正时用，答案写在 `n` 里。

新增章节就在 `DECK` 数组里加一个 `{ book, part, title, items: [] }`。改完刷新页面即可。
